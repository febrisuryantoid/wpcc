**WordPress Campus Connect (WPCC) UIN Sultan Maulana Hasanuddin Banten** adalah platform presentasi interaktif 3D modern yang didesain khusus untuk memberikan materi edukasi web development, Content Management System (CMS) WordPress, arsitektur web modern, hingga pengembangan karir IT bagi mahasiswa UIN Sultan Maulana Hasanuddin Banten, Serang.

Aplikasi ini menggabungkan mesin render 3D real-time berbasis WebGL (Three.js & React Three Fiber) dengan antarmuka UI/UX sinematik yang dirancang untuk performa tinggi, aksesibilitas prima, dan optimalisasi mesin pencari (SEO), AI Search Engine Optimization (AIO), Answer Engine Optimization (AEO), serta Generative Engine Optimization (GEO).

## 🌟 Fitur Unggulan & Teknologi Visual 3D

1. **Real Celestial 3D Object Core (Giant Sun 4K)**
   * Procedural 4K Plasma Shader ditenagai *Simplex Noise* & *Fractal Brownian Motion (FBM)* 6 octaves.
   * *View-Space Shader Mathematics* menjamin efek pendaran atmosfer (*solar corona*) dan bayangan (*limb darkening*) yang simetris & bebas distorsi di semua sudut kamera.
   * 12 Palet Warna Bintang Fiksi yang berubah secara dinamis sesuai klasifikasi slide.
2. **Audio Engine Interaktif**
   * Efek suara (*sound FX*) sinematik saat transisi slide, membuka profil pembicara, navigasi modal, dan pengalihan mode presentasi.
3. **Structured Breadcrumb & Quick Search**
   * Fitur pencarian pintar (Shortcut `Ctrl+K` atau `Cmd+K`) untuk melompat langsung ke slide atau materi tertentu secara cepat.
4. **Desain Responsif & Aksesibilitas Tinggi**
   * Kompatibel penuh dengan perangkat *desktop*, *tablet*, dan *mobile/smartphone*.

## 🚀 Panduan Memulai & Pengembangan Lokal

### Prasyarat
Pastikan mesin Anda memiliki **Node.js** (v18+) dan **npm** terinstal.

### 1. Kloning Repositori & Instalasi Dependensi
```bash
git clone https://github.com/febrisuryantoid/wp-campus-connect.git
cd wp-campus-connect
npm install
```

### 2. Menjalankan Server Pengembangan Lokal
```bash
npm run dev
```
Aplikasi akan berjalan secara otomatis di `http://localhost:3000`.

### 3. Kompilasi Produksi (Build)
```bash
npm run build
```
Hasil kompilasi statis siap deploy akan berada di direktori `/dist`.
